# Teameit — Complete Feature Map

## Architecture Decision
Make **Communication, Campaign, Automation, Publishing, CRM and Analytics** the core Teameit engines.
Then WhatsApp, Instagram, Facebook, Email, SMS, Meta, Google and YouTube become **providers/channels** plugged into those engines.
