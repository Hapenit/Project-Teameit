# Teameit

Welcome to the Teameit project!

## Overview
Teameit is a comprehensive platform featuring a web application frontend and a Supabase backend.

## Project Structure
- `apps/web/`: Contains the frontend web application.
- `supabase/`: Contains the backend database migrations and configuration.
- `docs/`: Project documentation and architecture details.
- `packages/`: Shared packages and utilities.

## Getting Started
To get started with development, make sure you have installed the necessary dependencies for both the frontend and backend.

## Documentation
Please refer to the `docs/` directory for detailed architecture, deployment, and development guidelines.
